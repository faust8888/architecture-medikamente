# Task1 — Анализ безопасности системы (As‑Is → To‑Be)

В этой директории лежит результат **Задания 1: анализ безопасности системы** для компании «Медикаменте».

## Состав

- `01-confidential-data.md` — категории данных, которые обрабатываются в компании (PII, мед. тайна, финансы и др.), и что именно «не учтено» в текущих системах.
- `02-dfd-as-is.md` — **DFD As‑Is** по ключевым бизнес‑процессам (каждый процесс отдельной диаграммой).
- `03-security-audit-and-problems.md` — аудит текущих мер безопасности и **список проблемных зон** (отдельным разделом).
- `04-improvements-and-tagging.md` — что улучшить: способы защиты данных (шифрование/обфускация/обезличивание), механизм **тегирования**, набор мер и инструментов.
- `05-dfd-to-be-with-controls.md` — **DFD To‑Be**: те же потоки, но с отмеченными контрольными мерами на этапах.

## Нотация DFD

Диаграммы даны в текстовом виде (Mermaid), по смыслу соответствуют гайду DFD (Lucidchart): процессы, внешние сущности, хранилища данных, потоки данных и контрольные меры.
