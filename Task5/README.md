# Task5 — Cutover‑план миграции

## Выбранная стратегия

**Parallel run** (параллельная эксплуатация старой и новой систем) с поэтапным переводом процессов и контролем расхождений.

Почему она подходит «Медикаменте»:
- As‑Is содержит **несколько источников истины** (Excel/сканы/почта/1С) → требуется период согласования и выверки данных.
- Есть критичные процессы (запись, приём, анализы, оплаты) → нужен **минимум простоя** и безопасный откат.
- Планируется рост и филиалы → удобно переводить по филиалам/процессам «волнами».

## Файлы

- `cutover-plan.md` — полный cutover‑план в требуемом табличном формате + пояснения, роли, риски, меры и план отката.
